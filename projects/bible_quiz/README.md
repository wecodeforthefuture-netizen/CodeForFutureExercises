# Bible Quiz Deluxe

## Project Overview

Welcome to your final Code for the Future project!

In this project, you will build your own interactive Bible Quiz game using everything you've learned throughout the summer.

Your quiz should ask Bible trivia questions, keep score, and encourage the player at the end.

---

# Learning Objectives

This project will help you practice:

- Variables
- Lists
- User Input
- If Statements
- For Loops
- While Loops
- Functions
- f-Strings

---

# Project Requirements

Your program must include:

- A main menu
- At least 10 Bible questions
- Questions stored inside a list
- Answers stored inside a list
- A score counter
- A final score
- Functions
- At least one loop
- If/Else statements

---
