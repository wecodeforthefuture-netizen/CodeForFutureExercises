# CodeForFutureExercises
## Using Technology to Serve God and Others

Welcome to the official repository for **Code for the Future**, a faith-centered Python coding camp designed for students ages **13–19**.

Throughout this program, students will learn the fundamentals of Python programming while discovering how technology can be used to glorify God and serve others.

By the end of the camp, students will build and present a Bible-based Python application.

> **"Each of you should use whatever gift you have received to serve others, as faithful stewards of God's grace in its various forms."**
>
> **— 1 Peter 4:10**

---

# 🎯 Learning Objectives

By the end of this program, students will be able to:

- Write beginner-friendly Python programs
- Understand variables, strings, user input, loops, functions, and more
- Debug common programming errors
- Think like a programmer and solve problems step-by-step
- Build and present a Bible-based application
- Use technology to serve God and others
