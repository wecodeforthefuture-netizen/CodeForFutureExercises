# Scripture Memory Trainer

## Project Overview

Build an interactive program that helps users practice memorizing Bible verses.

The program should display Scripture, give the user opportunities to practice, and provide feedback based on their answers.

Your goal is to create a useful and encouraging Scripture memory tool.

---

## Learning Objectives

This project will help you practice:

- Variables
- Strings
- Lists
- User Input
- If Statements
- For Loops
- While Loops
- Functions
- f-Strings

---

## Required Features

Your program must include:

- A main menu
- At least 5 Bible verses
- Verses stored in a list
- A way to select or practice a verse
- A memory challenge
- Feedback when the user answers
- A score or progress tracker
- Functions
- At least one loop
- If/Else statements

---

## Suggested Menu

1. Practice a Verse
2. View Verses
3. View Progress
4. Exit
